# Иви · Карточка контента

Тестовое задание по продуктовому дизайну и дизайн-системе. Я переработал карточку фильма и сериала для ситуации, когда человек открыл незнакомый тайтл и решает, смотреть его или нет. В репозитории — интерактивный рассказ о работе, мобильный прототип и библиотека компонентов, на которой он собран.

## Посмотреть результат

- [Кейс](https://sergeynaumovdesign-dot.github.io/ivi-test-task/case.html) — понимание задачи, исследование, гипотезы и решения с живыми примерами.
- [Прототип](https://sergeynaumovdesign-dot.github.io/ivi-test-task/prototype.html) — карточки фильма и сериала, просмотр моментов и переходы в плеер.
- [Иви Lab](https://sergeynaumovdesign-dot.github.io/ivi-test-task/design-system.html) — компоненты, варианты, состояния, поведение и примеры кода.
- [Figma](https://www.figma.com/design/JinDFmMxkLYtBfR8Az3EYL/Untitled?node-id=0-1) — исследование, макеты, UI Kit и спецификации.

Начать можно с кейса: он объясняет, как я пришёл к решениям. Прототип и компоненты доступны отдельно, без локального запуска.

## Что реализовано

- Персональное дополнение к описанию тайтла и обычное описание, если подходящей рекомендации нет.
- Моменты: видеопревью, вертикальные свайпы, пауза, перемотка, реакции и переход к просмотру с выбранной позиции.
- Краткое саммари отзывов с раскрытием полного текста.
- Рекомендация друга с переходом к остальным оценкам друзей.
- Общая библиотека компонентов, цветовые и текстовые токены, состояния и анимации взаимодействий.

На компьютере рядом с прототипом доступны настройки контента и отдельных блоков. На телефоне он занимает доступный экран, а настройки скрыты. В Иви Lab можно менять свойства компонентов и ширину предпросмотра.

## Запустить локально

Нужен Node.js. Устанавливать зависимости не требуется.

```sh
git clone https://github.com/sergeynaumovdesign-dot/ivi-test-task.git
cd ivi-test-task
npm start
```

Открой [http://127.0.0.1:4173](http://127.0.0.1:4173). Если репозиторий уже скачан, достаточно выполнить `npm start` из его папки. Альтернативная команда запуска — `node server.mjs`.

Проект написан на HTML, CSS и JavaScript, без сборки. Для работы модулей и загрузки видео страницы нужно открывать через сервер.

## Устройство проекта

| Файл или папка | Содержание |
| --- | --- |
| `index.html` | Стартовая страница со ссылками на материалы |
| `case.html`, `case.js`, `case.css` | Рассказ о кейсе и интерактивные примеры |
| `prototype.html`, `prototype.js`, `prototype.css` | Прототип и навигация между экранами |
| `prototype-data.js` | Данные фильмов, сериалов и моментов |
| `design-system.html`, `app.js`, `lab.css` | Иви Lab и настройки компонентов |
| `components/`, `tokens.css` | Переиспользуемые компоненты и токены |
| `assets/`, `reference/` | Медиа, шрифты, иконки и эталоны из Figma |
| `tests/` | Проверки поведения и сравнение с макетами |
| `server.mjs` | Локальный сервер с поддержкой загрузки видео по частям |

Карта вложенности компонентов — в [COMPONENTS.md](COMPONENTS.md). Подробное поведение и примеры использования можно посмотреть в Иви Lab.

## Границы прототипа

Описания, саммари, отзывы и оценки подготовлены для демонстрации. Персонализация переключается на заданных примерах. Возможность добавлять друзей — допущение концепции.

В плеере используются короткие фрагменты вместо полных фильмов и серий. Макеты и спецификации в Figma обновляются отдельно от кода.
